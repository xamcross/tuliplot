# TulipLot — AdSense launch checklist

Everything that must be true before switching the ad cell from the house promo
to live AdSense.

## 1. Content readiness
- [ ] 15–25 original, substantial guides/blog pages published (`content/`), all
      prerendered and crawlable (verify `find dist/frontend/browser -name index.html`).
      The five marketing/legal pages (Landing, About, Privacy, Terms, Contact)
      count toward the total public-page depth alongside the guides/blog pages.
- [ ] Landing, About, Privacy, Terms, Contact pages live with real copy.
- [ ] Privacy policy discloses Google/third-party advertising cookies, consent,
      and opt-out links (already shipped in `privacy.component.ts`).

## 2. Crawlability / SEO
- [ ] `robots.txt` served at root, allows `/`, disallows `/app`, references the sitemap.
- [ ] `sitemap.xml` served at root (generated by `scripts/build-content.mjs`).
- [ ] Per-route `<title>` + meta description + canonical (via `SeoService`).
- [ ] Submit the site + sitemap in Google Search Console.

## 3. ads.txt
- [ ] `https://tuliplot.com/ads.txt` returns, as `text/plain`:
      `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
- [ ] Replace `pub-XXXXXXXXXXXXXXXX` with the real AdSense publisher id.

## 4. Consent / CMP
- [ ] In the AdSense console, enable **Privacy & messaging → GDPR** (EEA/UK/CH)
      message; publish it.
- [ ] `environment.adsenseClient` set to the real `ca-pub-...` id (prod build).
- [ ] Verify in an EEA locale that `adsbygoogle.js` does NOT load until consent
      is granted (DevTools → Network), and DOES load after (ConsentService).

## 5. AdSense verification snippet + review
- [ ] Add the AdSense verification/auto-ads snippet where required. TulipLot loads
      the account script via `ConsentService.loadAdsScript()` after consent — the
      publisher id in `environment.adsenseClient` drives it. For site verification
      during review, add the AdSense `<meta name="google-adsense-account">` tag to
      the prerendered pages' `<head>` (index shell) if the console requests it.
- [ ] In AdSense, set the ad unit slot id and put it in the backend env
      `ADSENSE_SLOT`; set `ADSENSE_CLIENT` to the `ca-pub-...` id. `GET /config/ads`
      then returns non-empty `adClient`/`adSlot` and `AdCellComponent` renders the
      real `<ins>` instead of the house promo.

## 6. Crawler access to gated content
- [ ] The ad cell only appears on the logged-in dashboard. Reviewers judge the
      PUBLIC content site — keep the public pages ad-light and content-rich.
- [ ] If AdSense requests login access for review, provide a demo account with a
      FREE subscription so the ad cell + house promo are visible.

## 7. Go-live flip
- [ ] Set prod env `ADSENSE_CLIENT`, `ADSENSE_SLOT`, and `environment.adsenseClient`.
- [ ] Redeploy. FREE users now see live AdSense (after consent); Premium users
      never load any ad script or cookie.

## Expected timeline
- AdSense review typically takes a few days to ~2 weeks after submission. Content
  depth and clean policy pages (privacy/terms) are the biggest approval factors.
